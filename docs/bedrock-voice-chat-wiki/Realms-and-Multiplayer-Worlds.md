Currently, No. Bedrock Voice Chat does not work on Realms. BVC only works on Bedrock Dedicated Servers (BDS) or cross-platform Java Servers. You can support the development for Realms support by supporting Bedrock Voice Chat: https://discord.com/channels/1158951318166183936/1466979335255752899

Sponsors and Supporters will be the first to get access to Realms support. Your support enables me to dedicate time to working on solving this problem for all of us. : )

------

As far as I am aware, Realms run a slightly modified version of BDS. The major issue is that:

They don't support a way to configure a file on the server or a addon-setting.
@minecraft/server-net isn't supported there, meaning that the player position packets can't be sent from a Realm to BVC Server.

At the end of the day we need Mojang's support on this to either document a way around this, or to implement a few additional features for us to make BVC work on there.

----

My goal here is make sure whatever solution we have for Realms works regardless of the version of Minecraft you're playing - so whether you're on console, mobile, PC or in Java. It should just work and the setup should be the same. I don't want to offer a solution that only works for mobile but not our console brethren.

I have an idea of what could work for this, but as this evolves I'll share more info.
