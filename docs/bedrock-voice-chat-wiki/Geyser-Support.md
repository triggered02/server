YES. Bedrock Voice Chat works on cross-platform servers through the Fabric or PaperMC mod, available on Modrinth! https://modrinth.com/plugin/bedrock-voice-chat

Bedrock Voice Chat Server is _embedded_ into the Java mods, meaning _you do not need a separate server_ to run Bedrock Voice Chat. Simply install the mod, and configure it following the instructions over at https://github.com/Alaydriem/bedrock-voice-chat/wiki/Minecraft-Java-Support.
