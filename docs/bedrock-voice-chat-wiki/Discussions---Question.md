If you have questions or need support, there's a few resources to assist you:

1. For general discussions, Join my Discord: https://discord.gg/ahaSQPsM3C.
2. For more technical discussions, check out the Github Discussions page first, and if you have a question better suited for a more general audience ask a question there.

## Security Concerns

If you have a security concern, please use the Github Security tab to submit a private vulnerability report.

https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability

Please note at this time I am not entertaining "bug bounties". Legitimize security reports will be credited in the SECURITY.md file.
