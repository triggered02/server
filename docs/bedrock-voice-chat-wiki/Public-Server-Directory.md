I  don't maintain or promote a list of public servers. BVC is a mod that any server operator can install, so there's no central "official" server.

If you already play on a server you enjoy, ask your server owner or admin to install BVC — it's easy to set up, and the installation guide is available in the docs. That way you get proximity voice chat with a community you already know and trust.

Alternatively, if you or a friend can host a server, adding BVC is straightforward. Check the installation guide to get started.
