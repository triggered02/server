Your login URL is the URL of Bedrock Voice Chat Server **NOT** your Minecraft Server, Aternos Server, Nodecraft Server, or Game Server Address.

During the configuration of Bedrock Voice Chat Server (see https://github.com/Alaydriem/bedrock-voice-chat/wiki/BVC-Server-Installation) you define this value. It is also the value you issue a TLS certificate for.
